# Responsible AI Adoption Assessment

A 7-section, 49-question governance maturity assessment tool for Singapore organisations, aligned with the IMDA Model AI Governance Framework (MAIGF) and WSG GenAI Job-Task Model (JTM).

## Tech Stack

- **Vite** — build tooling and dev server
- **React 19** — UI framework
- **TypeScript** — type safety
- **Tailwind CSS v4** — utility-first styling
- **Recharts** — radar chart for maturity visualisation
- **Vercel** — deployment platform

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
